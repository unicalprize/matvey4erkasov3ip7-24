# Hotfix: cart-total

## Проблема

В стабильной версии (`main`) обнаружена критическая ошибка:
функция `cart_total` считала итоговую сумму корзины **без учёта количества**
каждой позиции. При заказе 3 мячей по 1000 ₽ функция возвращала 1000 ₽
вместо 3000 ₽, что приводило к неверным суммам заказов.

Исходная (сломанная) версия:

```python
def cart_total(cart):
    return sum(item['price'] for item in cart)   # без учёта количества
