## Какая ошибка была внесена?

В модуле `src/cart.py` в функции `add_to_cart` были намеренно внесены
изменения, ломающие взаимодействие с другими модулями:

1. Добавлена строка `raise Exception("Намеренная ошибка интеграции")`
   в самое начало функции — это имитирует критический сбой на стыке модулей.
2. Ключ словаря элемента корзины изменён с `"name"` на `"product"`:

item = {
    "id": product["id"],
    "product": product["name"],   # ОШИБКА: должно быть "name"
    "brand": product.get("brand", ""),
    "price": product["price"],
