# Руководство пользователя — «СпортТовары»

## 1. Введение

«СпортТовары» — консольное приложение для управления магазином спортивных
товаров. Подходит для небольших магазинов и учебных целей.

## 2. Установка

```bash
git clone git@github.com:Belomaster/SportShop.git
cd SportShop
```

Требуется Python 3.10+.

## 3. Запуск

```bash
python3.12 main.py
```

## 4. Основные сценарии

### 4.1. Просмотр каталога

Выберите пункт **1** в меню. Отобразятся все товары с полями:
`id`, `name`, `brand`, `category`, `price`, `quantity`.

### 4.2. Товары с низким остатком

Пункт **2**. Показывает товары с количеством ≤ 3 — удобно для
своевременного заказа новой партии.

### 4.3. Поиск

Пункт **3**. Введите название или бренд (регистр не важен). Например, `nike`.

### 4.4. Аналитика по категориям

Пункт **4**. Выводит словарь `{категория: количество}`.

### 4.5. Средняя цена

Пункт **5**. Показывает среднюю цену всех товаров.

### 4.6. Работа с корзиной

Пункт **6** — добавить товар по ID, размеру и количеству.
Пункт **7** — посмотреть содержимое корзины и итоговую сумму.

### 4.7. Оформление заказа

Пункт **8**. Введите имя клиента — заказ сохранится в `data/orders.json`.

### 4.8. Аналитика по заказам

Пункт **9**. Выводит выручку, средний чек и самый продаваемый товар.

## 5. Формат данных

`data/products.json`:
```json
[
  {"id": 1, "name": "Мяч Nike", "brand": "Nike", "category": "Игры", "price": 1500, "quantity": 5}
]
```

`data/orders.json`:
```json
[
  {"client": "Иван", "items": [...], "total": 3000, "created_at": "2026-10-08T10:00:00"}
]
```

## 6. Частые проблемы

| Проблема | Решение |
|----------|---------|
| `Ошибка: требуется Python 3.10+` | Используйте `python3.12 build.py` |
| `data/products.json не найден` | Создайте файл или восстановите из репозитория |
| Товар не находится при поиске | Проверьте раскладку, попробуйте часть названия |
| Корзина пуста при оформлении | Сначала добавьте товар через пункт 6 |
