# Руководство разработчика — «СпортТовары»

## 1. Архитектура

Приложение разделено на 5 модулей:

```
main.py
  ├─> src.storage    (загрузка/сохранение JSON)
  ├─> src.catalog    (каталог: низкий остаток, поиск, аналитика категорий)
  ├─> src.cart       (корзина: добавление, удаление, сумма)
  ├─> src.orders     (создание, печать, save/load заказов)
  └─> src.analytics  (выручка, топ товар, средний чек)
```

Модули обмениваются данными через **списки словарей единого формата**:

```python
{"id": int, "name": str, "brand": str, "price": float, "size": str, "quantity": int}
```

## 2. Сборка

```bash
python3.12 build.py
```

`build.py` выполняет:

1. `check_python_version()` — требует Python ≥ 3.10.
2. `check_data()` — проверяет наличие `data/products.json`.
3. `run_tests()` — запускает `unittest discover -s tests`.
4. `run_app()` — предлагает запустить `main.py`.

## 3. Тестирование

```bash
# Все тесты (модульные + интеграционные)
python3.12 -m unittest discover -s tests -v

# Только интеграционные
python3.12 -m unittest tests.test_integration -v

# Только модульные
python3.12 -m unittest tests.test_shop -v
```

## 4. Соглашения

- **Имена функций:** `snake_case`, глагол + объект (`get_low_stock`, `add_to_cart`).
- **Ключи словарей:** `id`, `name`, `brand`, `price`, `size`, `quantity` — единые во всех модулях.
- **Docstring:** для всех публичных функций.
- **Импорты:** абсолютные, от корня проекта (`from src.cart import add_to_cart`).

## 5. Как добавить новую функцию

1. Определите, к какому модулю относится функция (каталог, корзина, заказы, аналитика).
2. Добавьте функцию в соответствующий файл `src/*.py`.
3. Импортируйте её в `main.py`, если нужно в меню.
4. Напишите модульные тесты в `tests/test_shop.py` (или новом файле).
5. Напишите интеграционный тест, если функция взаимодействует с другими модулями.
6. Запустите `python3.12 build.py` — убедитесь, что всё ОК.
7. Закоммитьте: `git add . && git commit -m "US-X: добавлена функция ..."`.

## 6. Git Flow

- `main` — стабильная версия.
- `develop` — интеграционная ветка.
- `feature/<название>` — для новых функций.
- `hotfix/<название>` — срочные исправления в main.

## 7. Развёртывание

Проект не требует сервера — запускается локально:

```bash
git clone git@github.com:Belomaster/SportShop.git
cd SportShop
python3.12 main.py
```
