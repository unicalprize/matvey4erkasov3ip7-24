## Слайд 2. Цель и задачи

**Цель:** разработать консольное приложение для управления магазином
спортивных товаров с полным циклом — от каталога до аналитики продаж.

**Задачи:**

1. Реализовать работу с каталогом (поиск, низкий остаток, аналитика).
2. Реализовать корзину и оформление заказов.
3. Обеспечить сохранение данных в JSON.
4. Разделить монолит на модули (`src/`).
5. Написать модульные и интеграционные тесты.
6. Настроить скрипт сборки `build.py`.
7. Оформить документацию (README, API, User Guide, Developer Guide).

## Слайд 4. Основные функции

**Каталог:**
- `get_low_stock` — товары с низким остатком.
- `search_advanced` — поиск с фильтрами.
- `count_by_category`, `avg_price` — аналитика каталога.

**Корзина:**
- `add_to_cart`, `remove_from_cart`, `update_quantity`, `cart_total`.

**Заказы:**
- `create_order`, `print_order`, `save_orders`, `load_orders`.

**Аналитика по заказам:**
- `total_revenue`, `best_selling_product`, `average_order_total`.
