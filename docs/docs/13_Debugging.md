# Отладка (Debugging)

## Где была точка останова?
В файле `shop.py` внутри функции `get_low_stock` на строке с `return result`.

## Какие значения принимали переменные?
- `products` — список словарей с товарами (например, `[{'name': 'A', 'sizes': {40: 1}}]`).
- `threshold` — порог низкого остатка, по умолчанию `2`.
- `product` — текущий товар в цикле.
- `sizes` — словарь размеров, например `{40: 1}`.
- `stock` — значение остатка, например `1`.
- `result` — накапливаемый список товаров, попавших в выборку.

## Какая ошибка была найдена?
При первом запуске функция возвращала товары без ключа `sizes` (пустой словарь считался
подходящим, так как `any([])` = `False` — ошибки не было, но поведение было неочевидным).
После отладки добавлена явная проверка через `product.get('sizes', {})`, что исключило
`KeyError` при отсутствии ключа.

## Использованные приёмы
- **Step Over (F10)** — выполнял строки без захода внутрь вызовов.
- **Step Into (F11)** — заходил внутрь `any()` для проверки условия.
- Панель **Variables** — отслеживал `product`, `sizes`, `stock`, `result`.
