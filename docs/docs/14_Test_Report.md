## Найденные и исправленные ошибки
1. **`get_low_stock` падала с `KeyError`**, если у товара отсутствовал ключ `sizes`.
   Исправлено: заменено на `product.get('sizes', {})`.
2. **`add_to_cart` не проверяла доступный остаток** — можно было добавить больше,
   чем есть на складе. Добавлена проверка `quantity > available`.
3. **`update_quantity` не удаляла позицию при количестве ≤ 0.** Исправлено.

  через публичные.
