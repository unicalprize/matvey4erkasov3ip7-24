КОНТРОЛЬНЫЕ ВОПРОСЫ

1. Чем main отличается от develop в Git Flow?

main — стабильная ветка с продакшн-кодом, в неё попадают только релизы
и hotfix'ы. develop — ветка интеграции, куда вливаются все feature-ветки;
здесь код может быть нестабильным.


2. Зачем нужны feature-ветки?

Для изоляции разработки отдельной функции. Это позволяет вести
параллельную работу, не ломая develop, и удобно ревьюить изменения
через Pull Request.


3. Что такое конфликт слияния и как его разрешить?

Конфликт возникает, когда две ветки изменили один и тот же участок файла.
Разрешается вручную: открыть файл, найти маркеры <<<<<<<, =======, >>>>>>>
выбрать/объединить нужный вариант, удалить маркеры, затем git add
и git commit.


4. Что такое hotfix и когда он используется?

Hotfix — ветка от main для срочного исправления критической ошибки
в продакшене. После исправления вливается и в main, и в develop.


5. Зачем нужен Pull Request?

Для код-ревью, обсуждения изменений и контроля качества перед слиянием
в основную ветку. Позволяет команде проверить код, запустить CI
и оставить комментарии.


6. Как посмотреть граф истории коммитов?

git log --oneline --graph --all

Флаги: --oneline — краткий формат, --graph — ASCII-граф, --all — все ветки.
